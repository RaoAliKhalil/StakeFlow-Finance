# 🚀 StakeFlow Finance – DeFi Staking Project

## 💡 Overview

StakeFlow Finance is a decentralized finance (DeFi) project built using Solidity. It includes an ERC-20 token and a staking mechanism that allows users to earn rewards.

## 🔥 Features

* ERC-20 Token (SFT)
* Staking Smart Contract
* Reward Distribution Logic
* Deployed on Ethereum Sepolia Testnet
